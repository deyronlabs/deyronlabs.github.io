## What happened

On 11 November 2026 MiniMax published "MiniMax H3-Image: Bringing 4K Image Generation into the 10-Second Era". The company describes H3-Image as an open-weight image generation model built on its H3 model, supporting text-to-image generation, reference-based generation and image editing. TechNode reported the release the same day.

## Key details

Figures are MiniMax's, read from its announcement on 12 November 2026. We have not run the model, and the benchmark charts on the page are images we did not read.

- **Speed:** MiniMax says it generates a 4096 by 4096 (4K) image in under 10 seconds, up to 5x the speed of mainstream alternatives at 4K. It describes standard mode as 1.5 to 2x as fast as alternatives and a highspeed mode as 3 to 4x.
- **References:** up to 16 reference images per request.
- **Price:** MiniMax says pricing is 50 to 70% of comparable mainstream offerings, with a launch-week promotion of 50% off the standard price for requests at 4K and above.
- **Availability:** the MiniMax API Platform, MiniMax Code and Hailuo AI; the page links a Hugging Face repository for the weights.
- **Not stated in the text we read:** a license name, parameter count, or the comparison models behind the speed claims.

## Why it matters

Open weights for a 4K image model would let teams run and fine-tune it themselves, which hosted-only image models do not allow. That depends on the license, which MiniMax's page does not name, so check the Hugging Face model card before any commercial use.

The speed and price comparisons are MiniMax's, against unnamed alternatives. A fair test is the same prompts and reference images on your current tool, measuring both quality and total cost.
