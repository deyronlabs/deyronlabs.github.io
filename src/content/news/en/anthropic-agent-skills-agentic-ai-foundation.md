## What happened

On 22 October 2026 Anthropic announced that it is donating Agent Skills, which it describes as "the open standard that gives AI agents specialized knowledge and workflows", to the Agentic AI Foundation (AAIF). Anthropic makes Claude, the AI tool that helped draft this article, so please read this as a company describing its own project.

## Key details

All details are from Anthropic's announcement, checked on 23 October 2026. The adoption figures are Anthropic's and were not independently verified.

- **What a skill is:** "a folder containing a SKILL.md file". Anthropic published the standard in December 2025.
- **Adoption (Anthropic's figures):** more than 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot and VS Code, have integrated it; "1 million skills have been published and nearly 280 million installed".
- **Governance:** the AAIF sits under the Linux Foundation, which Anthropic says it co-founded with Block and OpenAI last year, and to which it donated the Model Context Protocol (MCP).
- **What is donated:** the Agent Skills name and logo, the GitHub organization and the agentskills.io domain. Anthropic says people can keep using or contribute to the standard without joining the AAIF.
- **Maintainers and roadmap:** engineers from Anthropic, Google, OpenAI and other companies will maintain it as individuals, with David Soria Parra and Mahesh Murag as Lead Maintainers. Proposed next steps are versioned releases, a formal proposal process and security guidance for people who write and install skills.

## Why it matters

Skills are plain folders that several competing products already read, so moving the standard to a neutral foundation addresses a common concern about one vendor controlling it. The planned security guidance is relevant because installed skills can carry instructions and scripts that an agent will run.
