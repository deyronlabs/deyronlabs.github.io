## What happened

On 7 October 2026, NVIDIA published a blog post about news from a Microsoft event in San Francisco. It says Microsoft Execution Containers (MXC) are now generally available and that NVIDIA's RTX Spark stack is coming to Windows laptops and compact desktops. Microsoft's Pavan Davuluri is quoted saying Microsoft is "building these primitives directly into Windows, so agents can be secured, observed and governed".

## Key details

All specifications and dates below are NVIDIA's.

- **Execution Containers:** described as OS-level infrastructure that lets agents run in the background under operating-system control, working alongside Microsoft Security and Agent 365.
- **RTX Spark specs:** a Blackwell RTX GPU with up to 6,144 cores, an up to 20-core NVIDIA Grace CPU connected at 600 GB/s, up to one petaflop of FP4 AI performance, and up to 128GB of unified memory.
- **Availability:** laptop preorders opened on 7 October, with general availability on 16 October. Compact desktops go on sale in November.
- **Partners:** Acer, ASUS, Dell, HP, Lenovo, Microsoft, MSI and Gigabyte. Microsoft built its Surface Laptop Ultra around RTX Spark.
- **DGX Station for Windows:** a preview of a deskside system with a GB300 Grace Blackwell Ultra superchip, 748GB of coherent memory and up to 20 petaFLOPS of FP4 compute. No release date was given.
- **Not in the post:** prices for any product.

## Why it matters

The notable change is the agent infrastructure: Windows is getting operating-system-level controls for running agents in the background, which is aimed at making them easier to secure and monitor. Whether that works as described will show up in security reviews and real deployments.

For buyers, the hardware matters mostly if you want to run large models locally, since up to 128GB of unified memory is more than most laptops offer. Without prices, and with performance figures that are all NVIDIA's own peak numbers, it is too early to compare these systems with alternatives.
