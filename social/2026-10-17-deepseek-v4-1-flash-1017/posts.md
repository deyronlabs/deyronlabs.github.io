## LinkedIn (pagina DeyronLabs) — linkedin-1200x627.png
DeepSeek updated its V4.1-Flash model on 17 October to a new snapshot, DeepSeek-V4.1-Flash-1017. The deepseek-flash name now points to it, in the API, web chat and app.

What DeepSeek says: the API calling method and pricing are unchanged; tasks run faster with shorter outputs than the previous V4.1; web and API search now use DeepSeek's own search engine. It lists 77.0 on DeepSWE v1.1.

What is worth noting: the benchmark figures are DeepSeek's own and the changelog gives no scores for the previous version, so the size of the gain is not shown. When we checked on 17 October, no 1017 repository had appeared on Hugging Face yet. Teams using deepseek-flash get the new model without changing code, so it is worth re-testing outputs.
